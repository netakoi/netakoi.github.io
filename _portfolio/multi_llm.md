This project aims to construct a browser-based environment where multiple commercial LLM agents can interact with each other. On top of the commercial agents, I will deploy a local agent to understand, summarize, and compress my request, which would reduce the token consumption. The main objective of the environment is to assist my programming using several languages and simulation platforms (Python, C++, IsaacLab, MATLAB) for robotic research.
